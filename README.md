# 🍰 Cakery Bakery Website

A responsive bakery website that I built while learning HTML, CSS, and JavaScript.

This is a learning/practice project where I focused on building a complete website layout and understanding how different parts of a responsive website work together.

## 🚀 What I Practiced

- HTML5 structure
- CSS3 styling
- Flexbox layouts
- Responsive web design
- CSS variables
- Navigation bar
- Mobile hamburger menu
- Hero section
- Product/category cards
- Buttons and hover effects
- Image layouts
- Newsletter section
- Footer layout
- Basic JavaScript DOM manipulation

## 📱 Responsive Design

The website is fully responsive and designed to work across different screen sizes, including desktop and mobile devices.

For smaller screens, the navigation changes into a hamburger menu using JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
